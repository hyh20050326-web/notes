# 打造个人第二大脑：数字花园实践

知识的价值不在于死记硬背，而在于网状互联与持续发酵。

---

## 1. 什么是“数字花园 (Digital Garden)”？

与传统的“瀑布流博客”按时间倒序排列不同，“数字花园”更加强调：
- **持续耕作与浇灌**：一篇文章可以从一个粗糙的想法种子（Seedling），慢慢修剪生长成参天大树（Evergreen）。
- **非线性双向链接**：概念与概念之间交叉引用，如同神经元网络。
- **公共学习（Learn in Public）**：在互联网上公开记录自己的成长足迹，连接志同道合的伙伴。
