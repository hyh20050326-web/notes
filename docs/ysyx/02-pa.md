# 02. PA 实验：打造体系结构模拟器 (NEMU)

PA（Programming Assignment）是理解计算机系统底层硬件与软件交互的最佳途径。

---

## 核心实验模块

### PA1：最简单的计算机与简易调试器 (sdb)
- 单步执行 `si`、打印寄存器 `info r`、扫描内存 `x`
- 表达式求值器（词法分析与递归求值）
- 监视点池 (Watchpoint) 设计与实现

### PA2：简单通信与指令集执行体系 (RV32E/I)
- 指令周期拆解：取指（Fetch）、译码（Decode）、执行（Execute）、更新 PC
- 追踪工具链：ITrace（指令轨迹）、MTrace（内存轨迹）、FTrace（函数调用追踪）

### PA3：输入输出与虚实结合 (IOE)
- 串口通信、时钟驱动、VGA 图形显存与按键输入
