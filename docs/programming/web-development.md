# 现代前端工程化指南

现代 Web 前端已经从早期简单的 HTML/CSS/JS 切图，演变为了高度工程化、模块化、组件化的完整软件工程体系。

---

## 1. 现代化工具链演进

- **打包构建**：Webpack $\rightarrow$ Vite / Rollup $\rightarrow$ Turbopack / Rolldown / Rspack
- **核心组件框架**：Vue 3 (Composition API) / React 19 / Svelte 5
- **静态文档与知识库**：VitePress, Astro, Next.js / Nextra, Docusaurus

---

## 2. 为什么选择 VitePress 作为知识库框架？

1. **以内容为中心**：基于 Markdown 编写，原生支持 Vue 语法与自定义组件。
2. **极速的开发体验**：基于 Vite，毫秒级热更新（HMR）。
3. **出色的生产性能**：预渲染为纯静态 HTML 页面，配合 SPA 客户端无感知跳转。
4. **轻量与现代审美**：官方主题设计极其洗练克制，专为沉浸式阅读与知识记录而生。
