# 02. 亚稳态与跨时钟域 (CDC) 设计

当信号在不同时钟域之间传递时，由于时钟相位和频率不相关，可能破坏建立时间或保持时间约束，导致触发器进入非高非低的震荡中间态，即**亚稳态 (Metastability)**。

---

## 1. 跨时钟域传输准则

### 单 Bit 信号传输
1. **慢时钟域 $\rightarrow$ 快时钟域**：双级触发器同步（“打两拍”）。
2. **快时钟域 $\rightarrow$ 慢时钟域**：必须进行**脉冲展宽**，防止快信号过窄而未被慢时钟采到。

### 多 Bit 信号传输
- 严禁直接使用打两拍同步多 bit 数据（因为各 bit 走线延迟不同可能产生中间脏数据）！
- **方案 A**：格雷码 (Gray Code) 转换（仅适用于连续递增变化的指针，如 FIFO 读写指针）。
- **方案 B**：DMUX 数据使能同步法。
- **方案 C**：握手协议 (Handshake) 或 异步 FIFO。
