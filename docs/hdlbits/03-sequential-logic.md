# 03. 时序逻辑电路设计 (Sequential Logic)

时序逻辑电路由存储元件（寄存器/触发器）和组合逻辑组合而成，电路的输出不仅取决于当前的输入信号，还取决于系统过去的历史状态。在芯片设计中，**D 触发器（D-FF）** 是构建寄存器、移位寄存器、计数器和状态机的物理基石。

---

## 1. D 触发器核心代码规范

在 HDLBits 中，触发器的考查重点在于**同步复位**、**异步复位**以及**使能控制端（Enable）**的 Verilog 建模规范：

### 1.1 同步复位 vs 异步复位

```verilog
// 1. 同步复位 D 触发器（只有时钟沿到来时才检测复位）
always @(posedge clk) begin
    if (!rst_n) begin
        q <= 1'b0;
    end else begin
        q <= d;
    end
end

// 2. 异步复位 D 触发器（复位信号跳变立即生效，无需等待时钟）
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        q <= 1'b0;
    end else begin
        q <= d;
    end
end
```

## 2. 经典真题精析：计算电路的有效建立与保持时间

> **题目来源**：HDLBits 进阶经典时序题 / 数字 IC 基础笔试真题  
> **题目要求**：下图中的电路，器件延时如图标注，将框内电路整体视为一个黑盒寄存器，求其在外部端口 `IN` 和 `CLK` 处的**有效 Setup Time 和 Hold Time**。

![时序电路拓扑图](/hdlbits-timing-circuit.png)

### 2.1 电路参数梳理

从电路拓扑中提取关键路径参数：
- **时钟路径延时 ($T_{clk}$)**：从外部 `CLK` 引脚经过反相器到达内部 D 触发器的时钟端，延时为 **$1\text{ ns}$**；
- **数据路径延时 ($T_{data}$)**：从外部 `IN` 引脚经过异或门（XOR）到达内部 D 触发器的 `D` 数据端，延时为 **$2\text{ ns}$**；
- **触发器内部参数**：
  - 内部建立时间 $T_{setup} = 2\text{ ns}$
  - 内部保持时间 $T_{hold} = 2\text{ ns}$
  - 时钟到输出延时 $T_{clk->Q} = 4\text{ ns}$（*干扰项！*）

---

### 2.2 形象化比喻：“摄影师拍照与演员入场”

为了**彻底理解物理本质**，我们不必死记公式，用一个生动的**“舞台拍照”**故事来拆解：

把黑盒内部的 **D 触发器** 想象成一个**“极其严苛的摄影师”**：
- **内部 $T_{setup} = 2\text{ ns}$**：按快门**前 2ns**，演员必须在舞台上站好，不许乱晃（提前量）；
- **内部 $T_{hold} = 2\text{ ns}$**：按快门**后 2ns**，演员必须继续保持定住，不许乱动（保持量）。

```
外部世界发令 (0ns) 
   │
   ├───────[延时 1ns 反相器]───────► 摄影师 (CLK端)
   │
   └───────[延时 2ns 异或门]───────► 舞台演员 (D端)
```

#### ① 摄影师什么时候按快门？
假设外部时钟口令在 **$0\text{ ns}$** 发出，但由于时钟线上有 $1\text{ ns}$ 延时的反相器：
> 相当于摄影师戴着耳机，口令传了 $1\text{ ns}$ 才传进耳朵。  
> 摄影师真正按下快门的物理时刻是：**$t_{clk} = 0 + 1 = 1\text{ ns}$**。

#### ② 摄影师对“舞台（D端）”的时序要求
因为摄影师在 **$1\text{ ns}$** 按下快门，按他的规矩：
- **站稳时间**：快门前 2ns，即 $1 - 2 = \mathbf{-1\text{ ns}}$ 之前，舞台上的演员必须就位站稳；
- **定住时间**：快门后 2ns，即 $1 + 2 = \mathbf{3\text{ ns}}$ 之前，舞台上的演员必须定住不许动。

---

### 2.3 站在大门口（外部引脚）逐步推导

现在，我们站在**整个大黑盒外面的大门口（外部 `IN` 和 `CLK` 端口）**来看：

#### 1. 计算有效建立时间（Effective Setup Time）
*问题：大门外的人（输入数据 IN）最迟什么时候必须到达大门口？*
- 舞台（D端）要求在 **$-1\text{ ns}$** 就位；
- 外部输入的数据要经过一条长达 **$2\text{ ns}$ 的走廊（异或门）** 才能传到舞台；
- 因此，外部数据最迟必须在：
  $$-1\text{ ns} - 2\text{ ns} = \mathbf{-3\text{ ns}}$$
  也就是在外部时钟到来（$0\text{ ns}$）的 **$3\text{ ns}$ 之前** 就必须稳定出现在输入端口！
- **结论**：**有效建立时间 $T_{setup(eff)} = \mathbf{3\text{ ns}}$**。

#### 2. 计算有效保持时间（Effective Hold Time）
*问题：外部时钟过去后，大门口的数据最早什么时候才能改变/换下一批人？*
- 舞台（D端）上的演员必须持续定住直到 **$3\text{ ns}$**；
- 如果大门口的数据发生了改变，这个变化也要走 **$2\text{ ns}$ 的走廊** 才会传到舞台；
- 所以，外部大门口的数据最早可以在：
  $$3\text{ ns} - 2\text{ ns} = \mathbf{1\text{ ns}}$$
  发生改变。因为即便它在 $1\text{ ns}$ 发生了跳变，传到舞台也已经是 $1 + 2 = 3\text{ ns}$ 了，刚好没有破坏上一拍的抓拍！
- **结论**：在外部时钟（$0\text{ ns}$）过去之后，输入端口的数据必须**继续保持稳定到 $1\text{ ns}$**。
- **结论**：**有效保持时间 $T_{hold(eff)} = \mathbf{1\text{ ns}}$**。

---

### 2.4 通用计算公式与秒杀口诀

遇到此类模块级引脚建立保持时间推导题，可直接套用物理定义公式：

| 物理指标 | 通用理论计算公式 | 本题代入计算 | 最终结果 |
| :--- | :--- | :--- | :--- |
| **有效建立时间** | $T_{setup(eff)} = T_{setup} + T_{data} - T_{clk}$ | $2\text{ ns} + 2\text{ ns} - 1\text{ ns}$ | **$3\text{ ns}$** |
| **有效保持时间** | $T_{hold(eff)} = T_{hold} - T_{data} + T_{clk}$ | $2\text{ ns} - 2\text{ ns} + 1\text{ ns}$ | **$1\text{ ns}$** |

::: tip 💡 核心记忆口诀
- **数据路径延时（$T_{data}$）**：帮倒忙！数据走得越慢，外部就必须越早准备好（建立时间**变大**，加号）；但新数据来得慢，旧数据在里面留得久（保持时间**变小**，减号）。
- **时钟路径延时（$T_{clk}$）**：推迟快门！时钟来得慢，给数据争取了更多到达时间（建立时间**变小**，减号）；但也让摄影师按快门变晚，要求外部必须等更久才能换数据（保持时间**变大**，加号）。
:::

### 2.5 常见陷阱与干扰项解析

1. **$T_{clk->Q} = 4\text{ ns}$（纯干扰项）**：
   - 触发器的 $T_{clk->Q}$ 决定的是**本级触发器输出数据到达下一级触发器的时间**，用于分析**后级**电路的时序；
   - 题目求的是**本级输入端口（IN/CLK）**的建立与保持时间，因此与输出端延时毫无关系。
2. **从 $Q$ 端反馈回异或门的连线（干扰项）**：
   - 题目问的是外部输入引脚 `IN` 的建立与保持时间。只要分析从外部引脚 `IN` 到触发器内部 `D` 端的最长/最短路径即可，反馈环路不影响建立保持时间的定义。
