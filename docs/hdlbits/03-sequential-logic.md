# 03. 时序逻辑电路设计 (Sequential Logic)

时序逻辑电路由存储元件（寄存器/触发器）和组合逻辑组合而成，输出不仅取决于当前输入，还取决于电路过去的历史状态。

---

## 核心题目分类

1. **D 触发器 (DFF)**：
   - 同步复位 vs 异步复位触发器
   - 带写使能端（Enable）的 D 触发器
2. **锁存器与移位寄存器**：
   - 线性反馈移位寄存器 (LFSR)
   - 移位计数器与 Ring Counter
3. **计数器 (Counters)**：
   - 十进制计数器、BCD 计数器、带自减/使能的递增计数器。
