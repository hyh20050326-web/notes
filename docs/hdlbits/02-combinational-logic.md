# 02. 组合逻辑电路设计 (Combinational Logic)

组合逻辑电路的输出仅取决于当前的输入信号，与过去的输入状态无关（无记忆性）。

---

## 核心要点

1. **避免不经意推断出锁存器 (Latch)**：
   - 在 `if-else` 分支中必须补齐 `else`；
   - 在 `case` 语句中必须提供 `default` 分支，或者在开头给出所有输出的默认值。
2. **多路选择器 (Multiplexer)**：
   - 2选1、4选1 MUX 的实现方式（三元运算符 vs `case` 语句）。
3. **加法器与 ALU**：
   - 溢出检测（正数+正数=负数 或 负数+负数=正数）。根据符号位判断
