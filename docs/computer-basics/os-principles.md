# 操作系统核心原理与进程调度

操作系统（Operating System, OS）是向下管理硬件资源、向上为应用程序提供抽象接口的核心系统软件。

---

## 1. 操作系统的四大核心职能

1. **处理器管理（CPU）**：进程控制块（PCB）、上下文切换、时间片轮转调度。
2. **内存管理**：虚拟内存机制、分段与分页、页面置换算法（LRU, FIFO）。
3. **文件系统**：inode 索引结构、目录树、VFS（虚拟文件系统层）。
4. **I/O 设备管理**：中断驱动、DMA（直接内存访问）、设备驱动程序。

---

## 2. 进程与线程的区别

::: info 核心概念提炼
- **进程 (Process)**：资源分配的基本单位。每个进程拥有独立的虚拟地址空间、文件描述符表等。
- **线程 (Thread)**：CPU 调度的基本单位。同一进程下的多个线程共享进程的内存地址空间和资源。
:::

| 维度 | 进程 | 线程 |
| :--- | :--- | :--- |
| **资源开销** | 较大，创建和销毁较慢 | 较小，上下文切换极快 |
| **内存隔离** | 独立隔离，安全性好 | 共享内存，需注意并发同步锁 |
| **通信机制** | IPC（管道、消息队列、共享内存、Socket） | 直接读写全局变量与堆内存 |
