# 现代工具链与随时随地在线编辑

很多同学在搭建完个人知识库后，最苦恼的一点就是：**“只能在写好代码的特定电脑上写笔记，换了手机、公司电脑或平板就无法更新”**。

通过本系统配合 GitHub，你将拥有**终身免费且全平台无缝在线编辑**的能力！

---

## 如何随时随地在线编辑笔记？

本套方案支持 **三种随时随地在线编辑模式**，你可以根据场景自由选择：

### 方式 1：最便捷 —— 页面底部一键「在 GitHub 上编辑此页」

1. 当你在浏览任意一篇笔记时，直接滑到文章底部；
2. 点击 **「在 GitHub 上编辑此页」** 按钮；
3. 浏览器会自动跳转到该文档在 GitHub 上的在线编辑界面；
4. 直接在网页里修改文字或追加笔记；
5. 点击右上角的 **「Commit changes...」** 提交保存；
6. **后台自动构建**：GitHub Actions 会在 1~2 分钟内自动完成编译并把最新内容推送到线上网站！

---

### 方式 2：最强大 —— GitHub Web 版 VS Code（按快捷键 `.`）

如果你需要同时修改多篇文章、新建文件或调整目录结构：

1. 在浏览器中打开你的 GitHub 笔记仓库页面；
2. 键盘直接轻按一下字母句号键 **`.`**（或者把网址中的 `github.com` 改成 `github.dev`）；
3. 浏览器会瞬间加载一个**原汁原味的 Web 版 VS Code 编辑器**！
4. 你可以在左侧目录树右键新建 `.md` 文件、批量重命名、拖拽上传图片；
5. 左侧切换到版本控制标签页，输入本次修改说明，点击 **「Commit & Push」**；
6. 线上站点便会自动同步更新！

::: tip 移动端/平板也适用
用 iPad 或手机浏览器打开 `github.dev` 同样可以轻量编辑和排版笔记。
:::

---

### 方式 3：最极客 —— 本地使用 Obsidian 或 VS Code 配合 Git

如果你在自己的常用电脑上：
1. 直接使用你喜欢的 Markdown 编辑器（如 VS Code、Typora、Obsidian、Cursor 等）编辑 `docs` 目录下的 `.md` 文件；
2. 命令行运行 `git add .`、`git commit -m "更新笔记"`、`git push`；
3. GitHub 同样会自动打包并发布。

---

## 如何新增一个笔记章节？

只需要两步：

1. **新建 Markdown 文件**：
   在 `docs/` 对应的分类文件夹（例如 `docs/computer-basics/`）下新建一个 `.md` 文件，例如 `my-new-note.md`。
2. **在侧边栏注册入口**：
   打开 `docs/.vitepress/config.mts`，在 `sidebar` 对应的列表项中追加：
   ```ts
   { text: '我的新笔记标题', link: '/computer-basics/my-new-note' }
   ```
3. 保存后刷新页面，侧边栏和大纲就会自动生成！
